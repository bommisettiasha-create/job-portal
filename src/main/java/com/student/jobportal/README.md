# Job Portal - Spring Boot Project

A complete Job Portal built with Spring Boot, JPA, Thymeleaf and MySQL/H2.

## Features
- Add New Job
- View All Jobs
- Edit Job
- Delete Job
- Search Job by Title/Company
- Premium Responsive UI

## Tech Stack
- Java 17, Spring Boot 3, Spring Data JPA, Thymeleaf, Bootstrap 5, H2/MySQL

## How to Run
1. Clone: git clone https://github.com/bommisettiasha-create/job-portal.git
2. Run: ./mvnw spring-boot:run
3. Open: http://localhost:8080
